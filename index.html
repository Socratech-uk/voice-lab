    A SMALL APP. REAL LOCAL ENGINES.
    Build it in cApp
    1. Add this source.
      Create a local project/application. Select the extracted folder or its ready-built index.html. No npm, backend or API key is required.
    2. Select Local AI.
      Use the updated Windows x64 Local AI 0.16.0+ Sidecar. Enable scoped app inference and scoped app speech. For character dialogue, set Dialogue authoring engines to Both. For sound effects and music, set Sound and music authoring to Stable Audio 3 · CPU / GPU. These add private runtimes at build time and produce one Setup.exe. Run it to install the application and its engine dependencies.
    3. Build and install.
      Compile a new release, package it for Windows and launch it. A plain browser preview cannot supply the native engines.
    4. Try a voice, then text.
      Click Enable voice; cApp manages the first-use downloads. Use Local AI Studio to choose a small GGUF or configure a baseline, then Prepare text. Run either engine separately before trying both. In Character dialogue, select a model, click Download & load model, then render your first take.
    No shell setup or system Python. The current speech engine requires Windows x64. First-time asset preparation needs connectivity; installed assets can be reused offline.
    This lab sends no application-level network requests and has no cloud fallback. Neural quality, latency and resource use depend on the installed models and device. Speech is text-to-audio; microphone input is not included.
